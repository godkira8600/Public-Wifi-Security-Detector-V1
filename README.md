# Public-Wifi-Security-Detector-V1
Public WiFi Security Detector is a cybersecurity-based project designed to identify potentially fake or malicious public WiFi networks, commonly known as Evil Twin attacks. These fake networks can trick users into connecting and may lead to data theft or security breaches.

This project works by scanning nearby WiFi networks and collecting important details such as SSID and BSSID. It then analyzes the networks to detect duplicate SSIDs with different MAC addresses, which is a common indicator of a fake or suspicious network. If such networks are found, the system alerts the user and highlights the potential risk.

The project is developed using Python and includes a simple graphical user interface built with Tkinter, making it easy for users to scan networks and view results. It helps improve awareness about public WiFi security and demonstrates basic concepts of network scanning and threat detection.

This project is mainly intended for educational purposes to understand how fake WiFi networks can be detected and how basic cybersecurity techniques can be applied in real-world scenarios.
